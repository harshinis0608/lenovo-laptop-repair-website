# Lenovo Laptop Repair Website

A responsive laptop repair and service website designed to provide information about laptop repair services, support, and contact details.

## Features

* Responsive website layout
* Hero section with promotional banners
* About Us section
* Laptop repair/service information
* Contact and support information
* Business hours information
* Custom image assets and branding

## Technologies Used

* HTML5
* CSS3
* JavaScript
